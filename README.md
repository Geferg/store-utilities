# Store Utilities
File dump repository for miscellaneous utility tools

## Setup
1. Go to the [official autohotkey page](https://www.autohotkey.com/download/)
2. Download the **ZIP** version
3. Unzip and place in desired path
4. Download `keybinds.ahk` from this repository
5. Replace the `AutoHotkey64.ahk` in the autohotkey folder, with this file (name needs to be exactly `AutoHotkey64.ahk`)
6. Run the utility with `AutoHotkey64.exe`

## Keybinds
### \<alt\>F1
Takes a single column of data from the clipboard and pastes each row one by one with enter separation.

### \<alt\>F2
Takes two columns of data from the clipboard and pastes each row by column left to right with tab separation.

**note:** _to denote empty shelf, use either `*fjern*` or `!fjern!`. The latter is prefered to avoid issues with internal tools._

### \<alt\>F3
Aborts long running tasks
